# 標準の声・アバター

独立版`uagav`の「声・アバター」から開始します。本体の`uagw`・`uaga`と
Agent / Memory / Sandbox / 認証は変更していません。追加サーバー・ポートも不要です。

| 選択肢 | 声 | 既定 |
| --- | --- | --- |
| 全力 マリン | marine | ○ |
| 全力 ハシロウ | hashiro | |
| 全力 キッカ | kikka | |

選択したアバターと同じIDのZEN-TTS音声を使います。音声のクローンやオリジナル素材の
制作は行いません。AIによる映像である旨と、権利者指定のリンク付きクレジットを画面に
表示します。

## 初回セットアップ

SDK・モデル・素材は独自ライセンスで、アプリ内利用は許可されていますが改変・再配布は
禁止されています。リポジトリ・wheel・sdist・CI成果物には含めません。
個人の利用環境で公式配布元から取得して使います。素材を公開・共有サーバーで配信する
運用や、配布物への同梱を行う場合は事前に権利者への確認が必要です。

- [ZEN-LipSyncライセンス1.0](https://github.com/zenryokukikai/zen-lipsync/blob/v1.1.0/LICENSE.md): 3章のクレジット・改変/再配布禁止と4章の標準アバター利用条件。
- [ZEN-TTSライセンス1.0](https://github.com/zenryokukikai/zen-tts/blob/v1.1.0/LICENSE.md): 3章のクレジット・改変/再配布禁止。
- [SDKの第三者ライセンス](https://github.com/zenryokukikai/zen-lipsync/blob/v1.1.0/THIRD_PARTY_NOTICES.md)と[TTSの第三者ライセンス](https://github.com/zenryokukikai/zen-tts/blob/v1.1.0/THIRD_PARTY_NOTICES.md)も公式取得物に保持します。

GitとNode.js/npmを用意します。公式SDKの推奨はNode.js 26.12.1以上です。
`uag-web`のチェックアウト先で実行します（Windows / Linux / macOS共通）。

```sh
python scripts/setup_avatar.py
uagav
```

既定の取得先はホームディレクトリの`.uagav/zen`です。公式1.1.0のコミットを固定し、
ソースを改変せずビルドします。3種類の音声モデルは公式CDNから取得し、公開SHA-256を
照合してから配置します。約230MB以上の素材に加え、ビルド用のディスク容量が必要です。
初回取得とSDKビルドにはネット接続が必要ですが、配置後のSDK・TTS・アバター処理は
同一オリジンから読み込み、ブラウザ内で実行します。LLM認証情報はサーバー側のままです。

場所を変える場合だけ、`UAGAV_ZEN_DIR`を指定します。スクリプトとWebの両方がこの
環境変数を使います。スクリプトはリポジトリ内への素材配置を拒否します。
取得先にある公式ソースを編集せず、更新は別PRでバージョン・ハッシュを検証します。
自動起動・自動ダウンロードはしません。

## 操作と制限

- 対応ブラウザのHTTPSまたはlocalhostで「アバターを開始」を押します。口パクには
  WebGPUが必要です。非対応環境でも既存のテキストチャットは利用できます。
- 返答の確定後、文ごとに音声を合成して口パク付きで読み上げます。コードブロックと画像URLは
  読み上げません。LLMのトークン到着中に読み上げる機能はまだありません。
- 「音声停止」は読み上げを停止します。既存の停止操作、次の入力、ルーム/セッション変更、
  切断、human_askでも読み上げを停止します。履歴や再接続時には読み直しません。
- アバター変更・パネルを閉じる操作でSDKと音声のリソースを解放します。
  自動再生が止められた場合は「再生を再開」を押します。
- 「話しかける」は対応ブラウザの音声認識を使い、確定結果を既存のチャットへ送ります。
  ブラウザ提供元に音声が送信される場合があります。初回のマイク許可が必要です。
  ブラウザ非対応時はボタンを出さず、テキスト入力を維持します。常時待受や自動VADはありません。
- ツール実行やhuman_askの回答は既存UIと既存のサーバー権限判定を使います。
  これはAIアバターであり、全力機械の公式アプリや実在の人物との会話ではありません。

## 検証

Nodeテストで確定文・置換・中断・履歴非再生・遅れて終了した合成のキャンセルを検証します。
Pythonテストで認証、素材パス制限、symlinkによる脱出拒否とJSのMIMEを検証します。
標準素材・声の実ブラウザ検証は別途実施し、PRに結果を記録します。CIには権利制限のある
素材を取得・アップロードしません。実マイク・実Provider会話・各実機での受入は別途必要です。

実ブラウザの再検証は、公式素材を配置して`uagav`を起動したうえで次を実行します。

```sh
npm install --prefix frontend --no-save --package-lock=false playwright@1.63.0
node frontend/node_modules/playwright/cli.js install chromium
node scripts/check_avatar_browser.mjs
```

WebSocketの返答だけをテスト側で送信し、実SDK・3種類の実声・アバターを使います。
音声バッファの再生開始・終了と切り替えを検証します。実LLM・マイクの検証ではありません。
このテストはWebGPUを使える検証端末で実行し、CIの必須テストには含めません。

### 再接続時のWebSocket通知

既存の`assistant_stream_start` / `assistant_stream_replace` / `assistant_stream_end`
を維持し、接続時に保持済みストリームを復元する通知だけ`"snapshot": true`を追加します。
既存チャット表示は従来どおり復元しますが、音声側はこのストリームを読み上げ対象にしません。
復元時点で処理中だったストリームも除外し、次の新しい返答から読み上げます。
通常のライブ通知と入力メッセージの形式は変えません。
