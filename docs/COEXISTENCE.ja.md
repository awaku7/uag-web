# 独立版の起動名はuagav

独立版は`uagav`（UAG Avatar）で起動します。パッケージ名は`uag-web`、
Pythonモジュールは`uag_web`です。本体のコード・起動名は変更しません。

| コマンド | アプリケーション |
| --- | --- |
| `uagav` / `python -m uag_web` | 独立版Web |
| `uagw` / `python -m uagent.web` | 既存の本体Web |
| `uaga` / `python -m uagent.a2a.server` | 既存のA2A |

両Webは既定ポート8000で、片方を停止して切り替えます。同時起動は非対応です。
追加ポートや常駐サービスは導入しません。独立版の削除後も本体Webと既存コマンドは
残します。A2Aスクリプトの改名や修正は不要です。

本体変更案#331・#332は未マージで取り下げ済み。#330は既存のマージ状態を維持。
独立版は本体mainの`71c5cd7`をGit依存として固定し、#330の既存APIを使用します。
OTel照会も既存の内部関数を参照し、本体に新たな公開APIを追加しません。
この限定的な内部依存はCore更新時の回帰検証対象です。

現在の公開UAGパッケージには#330のAPIがまだ含まれないため、開発版はGit依存を
自動導入します。同じバージョンの旧公開版をpipが保持する場合があるため、
開発版の導入にはREADMEの`--force-reinstall`付きコマンドを使用します。
PyPIへ公開する前に、#330を含む既存UAGリリースのバージョン依存へ
切り替える必要があります。本体側の変更・バージョン更新・公開は行いません。

認証・Origin・Sandboxの設定は維持します。実OIDC/実Provider/Web経由の実Sandbox、
表示・音声、CDN/フォントの配布方針は未検証項目として残します。
標準の声・アバターの導入は[専用手順](AVATAR.ja.md)を参照してください。
SDK・モデル・素材は同梱しません。
